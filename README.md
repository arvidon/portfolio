# Shagun Songara — Portfolio

A responsive personal portfolio matching the three supplied screenshots in `reference/`: white background, oversized black introduction, simple résumé sections, black skill labels, two bordered project cards, and a floating icon navigation dock. Built with HTML, CSS, and JavaScript with no build step.

Open `index.html` directly in a browser, or run `npm run dev` and visit http://localhost:5173.

## Content

Edit `portfolio.js` for project descriptions, direct repository URLs, live demos, LinkedIn, X, and email. Missing repository URLs link to https://github.com/arvidon. Experience and education are visibly pending until supplied. The reference owner's portrait and personal history are not used.

MushroomCode and AudioClassifier retain the supplied video files. Each project card includes an inline video preview and opens a full video player through either the preview or Demo button. MOV browser support depends on codecs; a fallback link opens the original file if playback fails. H.264 MP4 with AAC audio is recommended for broad browser support.

## Verification

`npm run check` validates JavaScript syntax. Google Fonts are optional and fall back to system sans-serif. The whole folder can be published to any static hosting service.
